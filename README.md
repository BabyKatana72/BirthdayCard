# 🎀 Tamara's 30th Birthday Card

A cute pastel birthday greeting card website made with love for Tamara Priskila Yawan's 30th birthday.

## ✨ Features

- Animated confetti & particles
- Pastel/kawaii aesthetic
- Interactive sparkle effects on click
- Fully responsive
- Zero dependencies (only Google Fonts CDN)

## 🚀 How to run

Just open `index.html` in any browser. No build step needed.

## 📸 Preview

```
index.html → open in browser → instant confetti party 🎉
```
